Order up. Let's learn SQL.

SQL is just a way of asking a database questions. Everything on this page runs for real, right in your browser, against a small made-up coffee chain called StarBean. Nothing to install, nothing you can break — every box with a dark background is a live console you can edit and re-run.

Three tables, one coffee chain

Think of each table below as its own spreadsheet tab. They're kept separate so information isn't repeated everywhere — a store's name lives in one place, not copied onto every order. In the Joins chapters you'll learn how to stitch them back together.

This starter is split into short stops rather than one long scroll — use the tabs above, in order, or jump straight to whichever bit you need: Basics, then Numbers, then two Joins chapters graded easy and trickier, then a Playground with nothing filled in for you.

Your first query

Most of what you'll eventually write is a variation on the shape below. Each part does one job — you don't need to remember all four yet, this is just the destination:

SELECT name, drink FROM orders WHERE size = 'Large' ORDER BY price DESC;
SELECT — which columns you want back FROM — which table to pull them from WHERE — which rows qualify ORDER BY — what order to hand them back in
